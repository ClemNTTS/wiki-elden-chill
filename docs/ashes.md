# Cendres de Guerre

## Fonctionnement

Une Cendre de Guerre :

- doit être équipée
- possède un nombre d'utilisations par expédition
- peut préparer un burst, une mitigation ou un proc de statut
- se recharge au boss ou au retour au camp selon la boucle en cours

## Cendres v2.3 notables

### Pas de l'Exécuteur

- orientation : exécution / saignement
- effet : gros multiplicateur sur le prochain coup + application de saignement

### Hurlement de Tempête draconique

- orientation : dragon / foudre / zone
- effet : renforce le prochain impact et applique une brûlure

### Litanie du Voile putride

- orientation : corruption / putréfaction
- effet : renforce le prochain coup et applique la putréfaction

### Rugissement du Colosse

- orientation : posture / armure
- effet : bonus d'armure temporaire et grosse frappe lourde

### Fracture Astrale

- orientation : mage astral / splash
- effet : zone, contrôle léger et setup de tempo

### Voeu du Garderacine

- orientation : tank racinaire / mitigation
- effet : armure temporaire + soin

## Lecture design

Les nouvelles cendres sont construites pour servir un archétype précis, pas comme bonus génériques.

Chaque cendre doit :

- avoir une identité claire
- être lisible dans le log de combat
- soutenir un build déjà existant ou un nouveau set
