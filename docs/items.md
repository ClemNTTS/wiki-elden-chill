# Équipement et panoplies

> Généré depuis le code local : **147 objets**, **29 panoplies**.

Le build tient dans trois emplacements : une arme, une armure et un accessoire. Les doublons améliorent l'objet. La rareté sert de signal visuel et de pondération de butin ; les synergies restent la vraie source de puissance.

## Direction visuelle actuelle

Les icônes viennent des atlas 16×16 du jeu. Les armes changent de métal avec leur niveau ; cadres et halos reprennent la rareté sans altérer la cellule.
