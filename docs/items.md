# Objets et rareté

## Rareté de loot

Les objets utilisent 4 paliers :

- `commun`
- `rare`
- `legendaire`
- `relique`

## À quoi sert la rareté ?

La rareté n'est pas juste cosmétique.

Elle impacte :

- le rendu visuel dans l'inventaire
- la lecture du tooltip
- la pondération des drops quand une run améliore la qualité du butin

Exemples d'effets qui poussent vers le haut les paliers rares :

- `Lentille de relique`
- certains événements de route
- certaines caravanes perdues

## Sets late-game v2.3

### Verdict de l'Exécuteur doré

- fantasy : saignement / exécution
- rôle : critique, pénétration, finishers

### Vestiges draconiques de Gelmir

- fantasy : dragon / foudre
- rôle : zone, intelligence, pression explosive

### Panoplie du colosse des arènes

- fantasy : gladiateur / posture / armure
- rôle : tank, mitigation boss, conversion armure -> force

### Liturgie du revenant noir

- fantasy : foi noire / putréfaction sans stat Foi
- rôle : résistances sombres, putréfaction, pénétration

## Accessoires build-defining

### Talisman de posture de duelliste

- augmente l'armure
- réduit les dégâts de boss
- convertit une partie de l'armure en force

### Talisman du couperet final

- renforce le critique
- pousse les builds d'exécution

### Talisman de tempête draconique

- augmente la zone
- soutient les builds foudre / draconiques

### Talisman de corruption rituelle

- convertit les résistances en pénétration et en critique
- synergise avec la préparation et les biomes dangereux

### Talisman du veilleur de sentier

- améliore l'économie de runes
- soutient les runs à événement / loot

## Lecture rapide d'un tooltip

Un bon tooltip v2.3 montre maintenant :

- le type d'objet
- la rareté
- les vraies stats qui changent
- les résistances ajoutées
- l'état du set après équipement

L'objectif n'est pas de tout afficher, mais de donner les changements réellement utiles pour la décision de build.
