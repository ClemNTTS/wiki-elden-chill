# Bien commencer

## La boucle fondamentale

1. Dépensez les runes sécurisées au camp.
2. Équipez une arme, une armure, un accessoire et une cendre.
3. Choisissez un biome adapté et préparez l’expédition.
4. Surveillez vos PV pendant les combats automatiques.
5. Rentrez sécuriser les runes portées, ou franchissez le cycle et son boss.

Les runes sécurisées survivent à la mort. Les runes portées sont perdues si l’expédition échoue.

## Premier build

- **Vigueur** si vous mourez avant le boss.
- **Force** pour des coups physiques directs.
- **Dextérité** pour la cadence, l’esquive et les statuts.
- **Intelligence** pour les dégâts magiques, efficaces contre l’armure.

Cherchez une identité simple plutôt que quatre statistiques égales. Construisez autour des effets dont vous satisfaites réellement les prérequis.

## Lire une défaite

- Monstres normaux trop meurtriers : manque de Vigueur, d’armure ou zone trop avancée.
- Boss presque intact : dégâts insuffisants, armure mal contournée ou set incomplet.
- Mort sous affliction : adaptez bénédiction, atout et résistances.
- Run rentable mais dangereuse : programmez l’arrêt après un cycle.

## Sauvegarde

La progression vit uniquement dans le navigateur, sans compte ni serveur. La sauvegarde locale est scellée, doublée d’une copie de secours et mise en quarantaine si elle est refusée. Ce scellement évite les retouches triviales ; ce n’est pas une sécurité contre un utilisateur déterminé.
