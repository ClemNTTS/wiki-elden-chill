# Équilibrage

## Philosophie générale

Elden Chill reste construit autour de trois idées :

- la puissance vient d'abord des synergies de build
- la montée de niveau soutient la progression, mais ne remplace pas la lecture du loot
- les biomes optionnels doivent être plus risqués et plus rentables, sans devenir obligatoires

La v2.3 ajoute des systèmes et du contenu, mais ne change pas le cœur du combat tour par tour.

## Cap de niveau

Le niveau maximum est maintenant **150**.

- `1-100` : fin du build principal
- `101-150` : spécialisation late-game

Ce surplus de niveaux sert surtout à absorber :

- la nouvelle route terrestre `Altus -> Gelmir -> Cimes -> Farum`
- les résistances de biome
- les nouvelles bénédictions et consommables
- les besoins défensifs du very late game

## Ce qui structure les runs

### Niveau

Le niveau augmente encore les fondamentaux :

- `Vigueur` pour les PV
- `Force` pour le cœur des dégâts
- `Dextérité` pour l'esquive, une partie de l'armure et certaines conversions
- `Intelligence` pour la force hybride, le splash et l'économie de runes

### Build

Le build fait la vraie différence via :

- les bonus de set 2 pièces / 3 pièces
- les accessoires “build-defining”
- les cendres de guerre
- la préparation
- la lecture des biomes et de leurs hazards

### Late-game v2.3

Les nouveaux archétypes ne doivent pas être interchangeables :

- **Verdict de l'Exécuteur doré** : critique, exécution, pénétration
- **Vestiges draconiques de Gelmir** : foudre, zone, intelligence explosive
- **Panoplie du colosse des arènes** : posture, armure, mitigation boss
- **Liturgie du revenant noir** : folie, putréfaction, scaling par résistances

## Rareté du loot

La rareté concerne bien les **items**.

Les quatre paliers sont :

- `commun`
- `rare`
- `legendaire`
- `relique`

Aujourd'hui, elle influence surtout :

- la lecture visuelle dans l'inventaire et les tooltips
- la pondération des drops quand une run augmente la qualité du butin

Exemples :

- `Lentille de relique`
- certaines caravanes perdues
- certains choix de route orientés avidité

La rareté n'est pas un second système de stats à la Diablo : elle sert d'abord de signal de valeur et de levier sur les tables de loot.

## Préparation et hazards

La préparation n'est pas là pour remplacer le build ; elle sert à lisser un biome précis.

Le modèle courant est volontairement simple :

- **1 bénédiction**
- **1 consommable**

Les hazards principaux sont :

- `Poison`
- `Gel`
- `Folie`
- `Putréfaction`

Le late-game est calibré pour que la préparation donne un avantage réel, sans être strictement obligatoire si le build est déjà très solide.

## Garde-fous pour les prochaines mises à jour

- ne pas gonfler les PV de boss sans leur donner un gimmick lisible
- ne pas faire des nouveaux sets des “+tout” universels
- garder les biomes optionnels plus rentables que la route principale, mais jamais indispensables
- conserver la lisibilité mobile du hub, de la carte et du combat
- éviter les systèmes qui demandent plus de clicks que de décisions
